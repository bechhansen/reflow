Updates come from production releases on GitHub (tags vX.Y.Z) and install only when you click Install. Alpha, beta and test builds are never downloaded: install those with Upload firmware file. Nothing installs while a reflow run is active, and the heater is switched off first. If a new firmware does not start properly, the controller returns to the previous one by itself.
