# Controller Enclosure

Houses the ESP32-C6 development board.

## Purpose
Protective enclosure that mounts near the iron. Provides cable routing for the I2C leads to the MLX90614 sensor bracket and USB/power access for the ESP32-C6.

## Print Settings
| Parameter | Value |
|-----------|-------|
| Material  | PETG or ABS (heat-resistant) |
| Layer height | 0.2 mm |
| Infill | 20% |
| Supports | None needed |

## BOM
- 4× M3×8 screws for board mounting
- 4× M3 heat-set inserts (if using threaded mounts)

## Notes
- Add a small ventilation slot if the enclosure will be near the iron
- Consider printing in a heat-resistant filament if ambient temperature near the iron exceeds 60°C
